# Kangeun Noh — Personal Website (In Progress)

This repository contains the source for a personal website that is being rebuilt. The current codebase is an interim Astro starter; its design and content will be replaced later.

For current engineering projects, see [my GitHub profile](https://github.com/thereisnoriver), including [TrafficG](https://github.com/thereisnoriver/TrafficG).

## Status

- **Under reconstruction:** portfolio content and technical posts are not yet published here.
- Demo articles from the starter theme are retained as unpublished drafts.
- The original starter theme is [Astro Sienna](https://github.com/anjay-goel/astro-sienna). Theme attribution and license remain with the original authors.

## Development

This repository uses Astro and pnpm. For local development, install dependencies with `pnpm install` and start the server with `pnpm dev`.
